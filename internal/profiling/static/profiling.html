Profiles
Heap memory
Current memory allocations. Shows what is holding memory and how much. Use to detect leaks.
go tool pprof HOST/debug/pprof/heap
Allocs memory
All past memory allocations since startup. Helps identify high-churn allocation paths.
go tool pprof HOST/debug/pprof/allocs
CPU cpu
30 second CPU sample. Shows which functions are consuming processor time during a scan cycle.
go tool pprof HOST/debug/pprof/profile?seconds=30
Goroutines runtime
All running goroutines and their stack traces. Use to detect leaks or unexpected goroutine growth.
go tool pprof HOST/debug/pprof/goroutine
Block runtime
Goroutine blocking events. Shows where goroutines wait on channels or mutexes.
go tool pprof HOST/debug/pprof/block
Mutex runtime
Mutex contention. Shows which locks are contested and causing goroutines to wait.
go tool pprof HOST/debug/pprof/mutex
Trace trace
10 second execution trace. Full timeline of goroutine activity, GC, and system calls.
go tool trace HOST/debug/pprof/trace?seconds=10
Threads runtime
OS threads created by the process. Should stay low and stable for a daemon.
go tool pprof HOST/debug/pprof/threadcreate
